## 场景一：反派在门外偷听/窥视

**剧情**：反派站在女主家门外，贴着门偷听屋里的谈话，手里攥着刚偷到的钥匙。

本场假设：竖屏；观众知道门外有人、屋里人不知道（经典悬疑信息差）；反派是「暗处的人」，不能拍得比屋里人还亮、还正。

拆戏：
- 冲突：屋里在谈一件会改变局面的事（比如遗产/证据），门外的人每多听一句，屋里人就多一分危险。
- 信息差：观众 > 屋里人。观众的紧张感来自「门随时可能被推开/声音随时可能惊动门外」。
- 转折点：屋里人说出最关键的那句话的那一秒，或反派手里的钥匙差点掉地的那一秒——镜头必须在这一刻有反应。
- 权力流向：表面上反派掌握信息占上风，但他是贴着门的、姿势卑微的——权力是「偷来的」，镜头要同时给出信息优势和姿态劣势。

### 低角度贴地仰拍（Low Angle）

出处：《Beethoven 贝多芬》（1992）· 导演 Brian Levant · 摄影 Victor J. Kemper；技法标签：1990s, Low Angle, Suspicion（标签来自 Eyecannndy，仅作参考；出处页：https://eyecannndy.com/search/ ）

为什么是它：拆戏要求「信息优势 + 姿态劣势」同时成立。镜头贴到地面仰拍，反派的脸和贴门的耳朵被压进画面上部，观众视线高度像趴在门缝边——既像和反派一起偷听（代入信息优势），又因为角度极端、人物被门板挤压而显得鬼祟卑微（姿态劣势）。一个机位同时解决两个要求，这是它当主推的理由。

换备选会损失什么：换备选 1（主观窥视）损失反派的表情表演，观众看不到他听到关键句时的反应；换备选 2（门框框中框）损失贴身感，悬疑变成「构图好看」，紧张度下降一档。

复刻级拆解：

| 字段 | 内容 |
|---|---|
| 景别 | 近景。反派头肩 + 一段门板占满画面，不给环境全景 |
| 机位 | 镜头中心距地约 35–45cm，仰角约 30–40°，位于反派侧前方、贴门一侧，距人物约 0.8m |
| 焦段感 | 35mm 感。轻微广角变形让贴门的耳朵和脸显大，门板线条向内倾斜，空间显窄显挤 |
| 构图 | 门板占画面左 2/3 作为大面积暗面；反派的脸在右上格，耳朵贴在门板中线；下方留一线门缝光（见光线） |
| 运镜 | 极慢推近：起点距 1.0m → 沿贴门方向斜推 → 速度约 5cm/秒（几乎察觉不到）→ 落点停在钥匙差点脱手的那一帧。推近的目的不是看清，是「越听越近、越近越危险」 |
| 时长 | 5–6 秒（短剧里算长镜，靠屋内台词的信息量撑住） |
| 光线与色调 | 走廊冷色顶光偏暗（色温感 5000K 偏青），门缝透出一线暖光（3000K 感）打在反派下巴和手上。照做法：实拍用走廊现有灯 + 门内开一盏暖灯只留门缝；AI 提示词直接写明冷暖对比 |
| 人物调度与表演 | 反派侧身贴门，耳朵贴门板，眼睛不看门、斜向下看（听声音时人会这样）；攥钥匙的手在画面下缘，听到关键句时手指收紧、钥匙轻晃但不掉 |
| 剪辑切点 | 切在屋里人说出关键信息词的那一帧，切回屋内正打——观众刚和反派一起听到，必须立刻看到屋里人浑然不觉的脸，信息差才扎人 |
| 声音提示 | 屋内人声隔门发闷（低通感），反派呼吸声近而清；钥匙轻碰的金属声在转折点放大 |

竖屏转译（横屏原构图 → 9:16）：
- 改了什么 1：横屏靠左右分割（门板左、脸右），竖屏宽度不够，改成上下分割：门板与耳朵在画面中上部，攥钥匙的手沉到下格——「脸在听、手在抖」上下呼应，正好用满竖屏纵深。
- 改了什么 2：门缝光在横屏是横贯底部的线，竖屏改成沿画面左边缘自上而下的一条竖线光，顺着观众滑动拇指的视线方向走。
- 改了什么 3：推近路径不变，但落点构图把脸放在上 1/3 格，避开底部字幕/UI 区（约下方 1/5 不放关键信息）。
- 为什么：竖屏观众的注意力是自上而下扫的，把「听」放上面、「危险的手」放下面，信息顺序和阅读顺序一致。

### 主观窥视视角（POV / Voyeur）

出处：《后窗 Rear Window》（1954）· 导演 Alfred Hitchcock · 摄影 Robert Burks——全片以主角的主观窥视视角组织悬疑，是窥视镜头的范式出处。

为什么成立：镜头即反派的眼睛，观众被强行按进反派位置，代入感和「共犯感」最强；适合偷听内容本身（屋里在干什么）比反派表情更重要的场次。
与主推的差异版拆解：景别随所窥内容定（屋内中景）；机位在门外高度约 160cm、透过猫眼/门缝，画面边缘带圆形或狭缝遮幅；运镜为手持轻微晃动 + 一次缓慢横摇跟随屋内人走位；时长 4 秒；光线为屋内正常暖光（与门外冷暗形成里外反差）；切点切在屋内人突然朝门口看过来的那一帧——主观镜头最怕被「看回来」。
竖屏转译要点：猫眼圆形遮幅在竖屏里改成上下黑边更宽的狭缝感（像透过门缝竖看），或直接全画幅 + 边缘暗角加重，避免圆形遮幅在竖屏里显小。
三份输出差异：实拍卡——机位改平视、加猫眼/门缝前景遮挡物，其余布光不变；AI 提示词——正向改「第一人称视角，透过门缝/猫眼看向屋内，画面边缘有门缝遮挡和暗角」，负向加「出现偷窥者本人的脸」；剪辑——切点改为「被看回来」帧，音效加一声屏住的呼吸。
换它损失什么：看不到反派表情，听到关键句的反应戏没了；且主观镜头连用会腻。

### 门框构图（Frame within Frame / Doorway）

出处：《搜索者 The Searchers》（1956）· 导演 John Ford · 摄影 Winton Hoch——结尾门洞框住人物的镜头是「框中框」的教科书范例。

为什么成立：门框把反派「框在门外」，构图本身就在说他是局外人、进不去这个家；适合需要同时交代空间关系（门里门外两个世界）的场次。
与主推的差异版拆解：景别中全景；机位在走廊尽头平视，门框完整入画成为内框，反派在框内贴门；运镜静止（为什么不动：框的稳定感反衬人物的鬼祟，一动就破）；时长 3–4 秒；光线为框外暗、框内（门缝与反派轮廓）微亮。
竖屏转译要点：门框本身就是竖长形，与 9:16 天然契合，是三个方案里转译成本最低的；把反派压在门框下 2/3，框顶留一截暗部压人。
三份输出差异：实拍卡——退到走廊尽头、机位高 150cm 平视、静止；AI 提示词——正向改「远景，走廊尽头的门框完整入画，框内一个身影贴门偷听，构图对称稳定」，负向加「镜头运动、构图倾斜」；剪辑——适合做整场的开场交代镜，音效先行（先闻其声）。
换它损失什么：距离远，贴身紧张感和表演细节都没了，悬疑靠构图不靠人。

## 场景二：女主发现男主隐瞒真相的决裂戏

**剧情**：女主在男主手机里看到聊天记录，当场明白他骗了自己大半年。她把手机放下，说：「我们分手吧。」

本场假设：竖屏；观众和女主同步知道真相（或比她早半步）；决裂不是吵架，是「心冷」——短剧里吵架戏好拍，冷决裂难拍，这场的镜头要解决的是「安静里的崩塌」。

拆戏：
- 冲突：不是「分不分」，是她发现自己大半年的信任是假的——冲突在她和「过去的自己」之间。
- 信息差：关键在转折的那一秒：她看完最后一条记录、抬眼看他的那一刻，信息差归零，权力反转开始。
- 转折点：抬眼的那一帧。此前镜头是「她的日常视角」，此后必须换一种看他的方式。
- 权力流向：开场男主掌控叙事（他在解释、他在圆），抬眼之后叙事权归她，镜头语言要跟着换边：他的画面开始「不稳/被分割」，她的画面开始「定」。

### 眩晕变焦（Dolly Zoom / Contra-Zoom）

出处：《迷魂记 Vertigo》（1958）· 导演 Alfred Hitchcock · 摄影 Robert Burks——该技法因本片成名，专为「天旋地转的认知崩塌」而生。

为什么是它：拆戏的转折点是「抬眼一秒、世界变样」。眩晕变焦让人物大小不变、背景却拉伸变形，正是「人还是那个人，但一切都不一样了」的视觉等式。只用在抬眼这一镜、2–3 秒，用完即止——决裂戏的崩塌感靠这一下，后面全部回到静止，冷才成立。

换备选会损失什么：换备选 1（长镜头静止）损失「崩塌瞬间」的外化，心冷有余、震感不足，适合更克制的剧；换备选 2（正反打拆解）损失奇观性，但换来关系疏离的细腻度，适合对手戏演员强的组。

复刻级拆解：

| 字段 | 内容 |
|---|---|
| 景别 | 女主近景，胸部以上，男主不入画（只闻其声或肩部虚影在前景一角） |
| 机位 | 与女主眼睛同高，平视，距约 1.2m，正面偏 15°（不完全正对，留一点「她在躲开他视线」的角度） |
| 焦段感 | 变焦过程：从 35mm 感拉至 85mm 感（或反向），人物占比不变，背景透视明显拉伸/压缩 |
| 构图 | 女主脸在画面中上格，眼睛在上 1/3 线；背景是两人同居的客厅——合照墙/双人沙发必须在背景里，变形时「家的空间」跟着扭曲才有意义 |
| 运镜 | 摄影机匀速后退（或前进）+ 同步反向变焦，2.5 秒完成，起幅稳、落幅稳，中途不许顿挫；落在她说出「我们分手吧」之前的那口吸气上 |
| 时长 | 2.5–3 秒，全场只此一次 |
| 光线与色调 | 暖色家居光在变焦中不变，但落幅后下一镜起整体降半档亮度、色温略冷——崩塌不靠本镜变色，靠前后对比 |
| 人物调度与表演 | 她低头看手机（上一镜内容）→ 缓慢抬眼 → 眼神先空一拍（不聚焦）→ 再聚焦到他脸上；不许哭、不许瞪，决裂戏的杀伤力在「平静」 |
| 剪辑切点 | 本镜从她抬眼动作开始前 0.2 秒切入；落幅定住后不切，留 0.5 秒静止再切男主反应——静止的那半秒是观众消化「完了」的时间 |
| 声音提示 | 变焦过程中环境声逐渐抽空（冰箱嗡鸣、窗外车声慢慢消失），只剩她的呼吸；落幅瞬间一声极轻的耳鸣感高频声，随即全静 |

竖屏转译：
- 改了什么 1：横屏眩晕变焦靠左右背景拉伸，竖屏横向空间窄，改靠纵深：让背景纵深变长——选有走廊/纵深家具的站位，变焦时身后的走廊「被拉长」，效果比横屏更明显。
- 改了什么 2：她的脸放在上 1/3，下方留出胸口和攥紧的手——变焦的「晕」在脸上，下方的手在抖，两个信息层上下叠放。
- 改了什么 3：背景里的合照墙在竖屏里安排在她头顶上方一格，变形时先被观众看到的是「他们的合照在扭曲」。
- 为什么：竖屏的透视变化主要发生在纵深轴和上下轴，把变形资产（走廊、合照墙）提前沿这两条轴布置，技法才不打折。

```
音乐/音效：变焦中环境声抽空+极轻耳鸣，落幅全静；她说「我们分手吧」时不进音乐，台词后2秒才进低沉的钢琴单音
```

### 静止长镜头（Static Long Take，全靠表演）

出处：《婚姻故事 Marriage Story》（2019）· 导演 Noah Baumbach · 摄影 Robbie Ryan——争吵/决裂段落以固定机位长镜头让表演自己升级，是「不炫技」的范式。

为什么成立：如果这场定位是「冷决裂」而非「震惊」，静止镜头把观众钉在房间里无处躲，压抑感随时间累积；且零运镜成本，实拍/AI 都最稳。
与主推的差异版拆解：景别双人中景同框；机位固定在房间一角、眼平；焦段 40mm 感不变；构图两人分居画面上下/前后（竖屏）两端，中间隔着茶几/餐桌形成「楚河汉界」；时长一镜 20–40 秒不切（短剧可拆成 2–3 个 8 秒段连拍）；表演调度靠走位：她起身、放下手机、走到窗边，距离越拉越大；切点只在她说出分手那句之后。
竖屏转译要点：横屏靠左右分开两人，竖屏改前后纵深分开：一人近景前景背对、一人远景在画面上部，距离感更狠。
三份输出差异：实拍卡——固定机位、一镜到底、排练走位优先于机位；AI 提示词——正向改「固定镜头，双人中景，女子缓缓起身走到窗边，背对男人，距离拉开」，负向加「镜头移动、切镜」；剪辑——几乎无切点，靠声音先行（她的台词压在男主反应画面上做 J/L cut）。
换它损失什么：没有「崩塌瞬间」的外化奇观，前 5 秒可能显得平；演员表演撑不住就整场垮。

### 正反打拆解（Shot Breakdown：从过肩到单人）

出处：《花样年华 In the Mood for Love》（2000）· 导演 王家卫 · 摄影 Christopher Doyle（杜可风）——大量用遮挡、镜面与「不给正脸同框」拍关系疏离，是正反打变体的经典参考。

为什么成立：决裂的视觉定义就是「两个人不再共享一个画面」。前半段还用过肩正反打（藕断丝连），抬眼之后突然全部拆成单人镜头、且各自带前景遮挡（门框、玻璃反光），观众会本能地感到「完了」。
与主推的差异版拆解：转折前过肩镜头各 2 个；转折后女主单人近景（前景虚化的门框边占左 1/4），男主单人近景（前景是鱼缸/玻璃的反光层）；焦段 85mm 感压缩、隔离两人；切点卡在每句台词的尾音，不留反应空镜，直到最后一句才给 1 秒空镜。
竖屏转译要点：过肩镜头在竖屏里把「肩」放在画面底部（而非侧边），被拍者居中上部，天然成立；遮挡物沿竖边放，比横屏更容易藏。
三份输出差异：实拍卡——镜数变多（6–8 镜），逐镜标遮挡物；AI 提示词——按镜拆成多条短提示词，每条注明前景遮挡；剪辑——本备选主要功夫在剪辑：前松后紧、尾音切。
换它损失什么：没有单镜名场面，传播性弱于眩晕变焦；镜数多，拍摄/AI 生成的工作量翻倍。

## 场景三：身份揭露的反转打脸戏

**剧情**：酒会上，女配当众嘲讽女主是「蹭吃蹭喝的穷亲戚」，众人哄笑。此时管家进门，恭敬地对女主说：「小姐，董事长请您去主桌。」全场安静。

本场假设：竖屏；观众提前知道女主身份（短剧主流：观众等打脸等了三集），女配不知道——这场戏的快感来自「权力翻转被全场目睹」。

拆戏：
- 冲突：公开羞辱 vs 真实身份，冲突不在两人之间，在「众人以为的秩序」和「真实秩序」之间。
- 信息差：观众 > 全场人。观众要的不是惊讶，是「翻转那一刻每个人的脸」。
- 转折点：管家那句「小姐」落音的瞬间。此前所有镜头为羞辱蓄势，此后所有镜头为打脸兑现。
- 权力流向：开场女配站着、女主坐着（物理高低 = 权力高低）；翻转后必须完成物理反转：女主起身、女配僵在原地，镜头机位跟着「换边站」。

### 低角度权力仰拍（Low Angle Power Shot，机位换边）

出处：《公民凯恩 Citizen Kane》（1941）· 导演 Orson Welles · 摄影 Gregg Toland——低角度仰拍 + 深焦是「权力人物」的奠基性拍法（标签体系中 Low Angle 一类，Eyecannndy 亦有收录，仅作参考）。

为什么是它：打脸戏的本质是权力易主，而机位高度是观众潜意识里最直接的权力刻度。前半段女主被俯拍（坐着、被围着、镜头从女配肩头压下来）；管家话音落，女主起身，镜头降到腰部以下仰拍她——同一个演员、同一张脸，机位一换，观众立刻「站队完成」。主推的完整设计是「俯拍蓄势 → 仰拍兑现」的一对镜头，单用仰拍只有一半效果。

换备选会损失什么：换备选 1（缓慢推近）损失全场维度，打脸变成两人私事，围观者的脸没了，爽感减半；换备选 2（环绕运镜）损失机位刻度的干脆，环绕更「炫」，但权力感不如仰拍一锤定音。

复刻级拆解（兑现镜，即仰拍镜）：

| 字段 | 内容 |
|---|---|
| 景别 | 女主中近景，起身动作从坐姿到站直在一镜内完成 |
| 机位 | 镜头中心距地约 60–70cm（坐姿人群的腰线以下），仰角约 20–25°，位于女主正前方偏右约 2m |
| 焦段感 | 40mm 感。略广，带一点「空间向她打开」的扩张感，但不变形脸 |
| 构图 | 女主起身后头顶接近画面上格，居中偏上；前景下角是坐着的宾客肩背（虚化），他们从「围观者」变成「仰望者」；女配被挤到画面边缘虚焦区，只留半张僵住的脸 |
| 运镜 | 随起身动作同步缓升 + 微推：起点距地 60cm → 沿小弧线升至 90cm → 速度与起身同步（约 2 秒）→ 落点在她站直、目光平扫全场的那一帧定住。升是为了「陪她站起来」，定住是为了「让全场看她」 |
| 时长 | 3.5–4 秒（起身 2 秒 + 定住环视 1.5 秒） |
| 光线与色调 | 酒会暖金光不变，但她起身后正好进入吊灯主光区，脸比前半段亮半档——不是换灯，是调度让她「走进光里」；女配留在偏暗的侧光区 |
| 人物调度与表演 | 女主：不急着起，先放下酒杯（0.5 秒）→ 扶桌起身 → 站直后不看女配，先平扫全场 → 最后才把目光落到女配脸上，微微一笑（笑是最后一刀，必须最后给）；女配：笑声在「小姐」落音时戛然而止，杯子停在半空 |
| 剪辑切点 | 管家台词「小姐」二字落音帧，切女主放杯子的手部特写 0.8 秒（蓄力），再切本镜起身；本镜定住后切女配僵脸特写 1.5 秒，再切全场安静的全景 |
| 声音提示 | 「小姐」落音后全场人声、餐具声在 0.5 秒内全部抽掉，只留一声水晶杯轻碰的余响；她起身时音乐低音弦乐缓入，定住瞬间停在单音 |

竖屏转译：
- 改了什么 1：横屏仰拍靠人物在宽幅里「顶天立地」，竖屏人物本来就容易顶满，改靠「高度差分层」：坐着的宾客压在画面最下格（只露头顶/肩背），女主站直后占满中上部，女配的脸卡在中间一格虚焦——三层权力一屏看清。
- 改了什么 2：原构图的左右平扫环视，在竖屏改成「目光由远及近」：先看画面上方远处宾客，再落回中格女配，视线走纵深不走横向。
- 改了什么 3：前景宾客肩背在横屏放两侧，竖屏放底部一格，正好避开字幕区又当了「仰望者」的画框。
- 为什么：竖屏的权力刻度是纵轴——谁在上、谁在下，一目了然；把三层人物沿纵轴排好，打脸信息零损耗。

### 缓慢推近特写（Slow Push-in）

出处：《教父 The Godfather》（1972）· 导演 Francis Ford Coppola · 摄影 Gordon Willis——开场对 Bonasera 的极慢推近是「推近=权力/命运逼近」的经典范式。

为什么成立：把打脸收成女主一个人的内心戏：全场声音退远，镜头从中景用 6–8 秒推到大特写，她的表情从隐忍到从容，观众在推近中完成站队。适合女主表演细腻、想走「高级感」而非爽剧感的版本。
与主推的差异版拆解：景别中景→大特写一镜完成；机位眼平（不仰拍，权力靠距离不靠角度）；焦段 85mm 感；运镜匀速推近 6–8 秒，速度恒定不许变速；切点在推满后停 1 秒再切女配。
竖屏转译要点：竖屏推近时脸的占比增长更快，起始景别要比横屏再松一档（从中全景起推），否则推满时脸溢出画面。
三份输出差异：实拍卡——轨道/稳定器慢推，焦点全程锁眼；AI 提示词——正向改「镜头用8秒匀速缓慢推近，从中景到面部大特写」，负向加「推近速度变化、突然跳切」；剪辑——本镜不可剪断，音效做主观化处理（全场声渐闷渐远）。
换它损失什么：全场反应没了，打脸的「公开处刑」感减半；8 秒单镜对短剧节奏是冒险。

### 环绕运镜（Orbit / Arc Shot）

出处：《大白鲨 Jaws》（1975）之外更贴切的是现代短剧/广告常用的环绕揭示——经典出处可举《黑客帝国 The Matrix》（1999）· 导演 Wachowskis · 摄影 Bill Pope 的子弹时间环绕：镜头环绕主体一周，世界为之静止，专为「全场为这个人停住」设计。

为什么成立：管家话音落，镜头以女主为圆心环绕 90–120°，背景里宾客的脸一张张转过来、女配从画面中心被甩到边缘——「世界围着她转」就是字面意思的权力翻转。
与主推的差异版拆解：景别中景；机位眼平、半径约 2m 弧线移动；时长 4–5 秒走完 100° 左右；落幅构图与主推相同（女主中上、女配边缘虚焦）；背景人物在环绕中依次转头，形成波浪式反应。
竖屏转译要点：竖屏环绕时背景横移速度感更强，半径要放大到 2.5–3m、角度收到 90° 以内，防晕；人物始终保持在画面中上格，靠移动背景而不是移动人物。
三份输出差异：实拍卡——需稳定器走弧线、地面贴标记点；AI 提示词——正向改「镜头以女主为圆心缓慢环绕约90度，背景宾客依次转头看向她」，负向加「背景人物脸部扭曲、环绕过快」；剪辑——环绕镜前后各接一个静止镜，动静对比才显出环绕。
换它损失什么：机位刻度的干脆没了，且 AI 生成环绕镜头时背景人脸最容易崩，废片率高。
